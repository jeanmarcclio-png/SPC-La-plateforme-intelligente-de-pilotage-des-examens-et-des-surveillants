# SPC-La-plateforme-intelligente-de-pilotage-des-examens-et-des-surveillants
SPC est une plateforme SaaS intelligente de gestion des examens et des surveillants permettant de planifier les salles, calculer automatiquement les heures facturables, générer les devis, affecter les surveillants et piloter les sessions d’examens de bout en bout.
